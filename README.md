## Info

<img width="100px" src="assets/logo.png" align="right">

本项目是 [UCDT Series 系列软件](https://ucdt-app.vercel.app/)中的一款产品。

本项目为 UCDT Processing GUI （城市建筑空间数据自动化聚合和导出）核心算法的图形（GUI）界面程序，为便于使用而进行开发的。
